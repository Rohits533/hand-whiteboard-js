# 🖐️ Hand Tracking Whiteboard

Draw in the air using your fingers! A JavaScript-based whiteboard with camera hand tracking.

## ✨ Features

- 🖐️ **Hand Tracking**: Uses MediaPipe for accurate hand detection
- ✏️ **Air Drawing**: Move your index finger to draw
- ✊ **Fist Control**: Make a fist to pause drawing
- 🎨 **Color Picker**: Choose any color
- 📏 **Brush Size**: Adjust stroke thickness
- ↩️ **Undo/Redo**: Full history management
- 💾 **Export**: Download as PNG
- 🖱️ **Mouse Support**: Also works with mouse/trackpad

## 🚀 Live Demo

[Click here to try it live!](https://hand-whiteboard-js.vercel.app)

## 🛠️ Technology

- **HTML/CSS/JavaScript** - Frontend
- **MediaPipe** - Hand tracking
- **Canvas API** - Drawing
- **Vercel** - Hosting

## 🎯 How to Use

1. Click **"Start Tracking"**
2. Allow camera access
3. Show your hand to the camera
4. Extend index finger to draw
5. Make a fist to pause
6. Use sidebar to change colors and brush size

### Gestures

| Gesture | Action |
|---------|--------|
| ☝️ Index finger up | Draw |
| ✊ Fist | Pause |
| 👋 All fingers | Idle |

## 🚀 Deployment

### Deploy on Vercel

1. Fork this repository
2. Go to [Vercel](https://vercel.com)
3. Click "Add New" → "Project"
4. Import your GitHub repo
5. Click "Deploy"

### Deploy on GitHub Pages

1. Go to repo Settings → Pages
2. Set source to "main" branch
3. Your site will be live at: `https://username.github.io/hand-whiteboard-js`
